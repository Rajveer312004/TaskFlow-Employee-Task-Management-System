# TaskFlow — Employee Task Management System

TaskFlow is a React application for assigning tasks to employees and tracking their progress.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Planned Features

- Employee management
- Task assignment
- Task status tracking
- Task priorities and deadlines
- Employee dashboard
